# 덕형 수학 배틀존

수업용 실시간 그래프 채점 앱. 학생이 미분으로 그린 그래프 개형을 사진으로 올리면 AI가 항목별로 채점하고, 선생님 화면에 1위가 실시간으로 표시됩니다.

## 이전 버전(geomsan)과 달라진 점
- 이름: 검산소 → **덕형 수학 배틀존**
- 출제: 문제를 **사진으로 업로드 + 필요한 부분만 크롭**. 문제 글 입력도 가능(병행 가능).
- 모범답안 칸: **수식 편집기(버튼식 + 실시간 미리보기)** 로 정답 함수 입력, 또는 **모범답안 사진** 업로드. **비워두면 AI가 스스로 모범답안을 만들어 채점.**
- **정답 그래프**: 출제할 때 **한 번만** 생성해 저장 → 학생 채점 결과에 그림으로 표시(채점 속도에 영향 없음). 곡선으로 그릴 수 없는 식(정적분 값·수열 합 등)은 글 설명만.
- 학생: 답안 사진도 **크롭 가능**. 학생 화면에 문제 사진 표시.

## 배포 방법
geomsan과 동일합니다. 새 GitHub 저장소에 이 폴더(server.js, package.json, README.md, .gitignore, public/index.html)를 올리고, Railway에서 연결한 뒤 환경변수 `ANTHROPIC_API_KEY`를 넣고 도메인을 생성하세요. **public 폴더 안에 index.html이 들어가야 합니다.**

기존 geomsan을 그대로 두고 새 프로젝트로 배포하면, 검증될 때까지 현재 수업용 버전이 끊기지 않습니다.

## 참고
- 출제 시 정답 그래프 생성에 AI 호출이 1회 추가됩니다(문제당 1번뿐이라 비용 영향은 미미).
- 데이터는 서버 메모리에만 임시 저장되며 재시작 시 사라집니다(미성년자 데이터 보호).

## 추가된 기능 (공개 조절 · CSV · 강점 요약)
- **단계별 공개**: 선생님 순위 화면의 버튼으로 1등 → 2등 → 3등 → 전체 순으로 공개. 기본은 가림 상태라 TV에는 "N명 제출"만 보이고, 버튼을 누른 만큼만 등수가 나타납니다. "다시 가리기"로 되돌릴 수 있어요.
  - 공개 버튼과 안내 문구는 선생님 화면에만 표시됩니다. TV로 미러링하면 공개한 만큼만 학생에게 보여요. (TV에는 순위 화면만 띄우고, 선생님은 같은 화면을 본인 기기에서도 열어 조작하는 방식을 권합니다.)
- **새로고침 대비**: 진행 중 순위와 공개 단계가 브라우저에 임시 저장돼, 실수로 새로고침해도 복구됩니다.
- **CSV 내려받기**: "CSV 내려받기" 버튼으로 순위·학번·이름·점수·강점요약·채점요약·제출시각을 파일로 저장(엑셀 한글 깨짐 방지 처리). 수업 후 정리에 사용하세요.
- **강점 요약**: 채점 시 학생이 특히 잘한 점을 한 줄로 요약해, 순위판과 학생 결과 화면에 함께 표시합니다.

> 주의: 임시 저장은 그 브라우저에만 남습니다. 다른 기기·시크릿창에서는 안 보이며, 영구 보관은 CSV 내려받기로 하세요.
